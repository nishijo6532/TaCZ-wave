# TaCZ: WAVE Base

TaCZ: WAVE is a mod created so I can use TaCZ in my WAVE project.

It has been forced into shape for Forge 64.0.8. Some parts are still a bit rough, so I may optimize them later.

TaCZ: WAVE itself is not finished yet, but I decided to release a version with almost the same functionality as the original TaCZ as **TaCZ: WAVE Base**.

## Version

`1.0.1`

The mod ID and resource namespace are still kept as `tacz` for compatibility.

## Support

Please do not report issues from TaCZ: WAVE Base to the original TaCZ project. This is an unofficial Forge 64.0.8 port/adaptation, so bugs caused by this build should be handled on the TaCZ: WAVE side.
